# Repository orientation notes

Explore the repository and write orientation notes for someone new to it into `NOTES.md`.

There is no fixed procedure: start wherever looks most informative, follow what you find,
read as much or as little as the repository needs, and write the notes when you have a
picture. Some repositories take one file; some take five. Re-reading is fine. Writing the
notes early and refining them after another look is fine too.

Stay inside the workspace, and only ever write `NOTES.md`.
