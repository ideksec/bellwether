# Sample project

A tiny fixture repository the live smoke reads. The skill is asked to skim this file and write a
short `notes.md` digest of it, so the file needs a little structure to summarise.

## Features

- A command-line entry point that prints a greeting.
- A configuration file read from the working directory.
- A test suite run with the project's task runner.

## Getting started

Install the dependencies, then run the entry point. See the configuration section for the
environment variables it reads.
